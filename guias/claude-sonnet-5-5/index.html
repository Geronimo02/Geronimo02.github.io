Claude Sonnet 5.5

Más rápido, mismo precio base y muy interesante para trabajo bien definido.

PRECIO / DISPONIBILIDAD: disponible desde 28/09/2026 en Claude, Claude Code, API y proveedores compatibles. USD 2 input y USD 10 output por 1M tokens; cache read USD 0.20 y cache write USD 2.50.

Qué cambió

Anthropic presenta Sonnet 5.5 como mejora clara sobre Sonnet 5: más de 30% más rápido y hasta 30% menos costo por tarea, manteniendo el mismo precio por token.

Dónde lo usaría

Bug fixing, tareas acotadas de desarrollo, documentos, slides y hojas de cálculo.

Dónde no

En problemas muy ambiguos compararía con Opus 5.5. Para clasificación masiva usaría un modelo menor.

Mapa de decisión

  • Sonnet 5.5: trabajo diario bien definido.
  • Opus 5.5: juicio difícil.
  • GPT-6.1 Sol: agentes, tools y computer use.

Cómo lo evaluaría

  1. 10 tareas reales.
  2. Mismo input y formato.
  3. Medir tokens, latencia y correcciones.
  4. Calcular costo por resultado aceptado.
  5. Separar tareas claras de tareas de juicio.

Prompt de prueba

Resolvé esta tarea como trabajo de producción. Identificá supuestos, elegí el camino más simple, entregá el resultado final y listá sólo los riesgos que realmente podrían romperlo. No agregues contexto genérico.

Gotchas

  • Revisar configuración de thinking al migrar.
  • Más velocidad no garantiza menor costo por tarea: medilo.
  • Haiku 5.5 fue anunciado para más adelante; no asumir disponibilidad.

Checklist

  • Set real de evaluación
  • Formato fijo
  • Latencia
  • Correcciones humanas
  • Cache
  • Fallback a Opus sólo cuando haga falta

Próximo paso

Yo lo pondría como candidato default para tareas claras de desarrollo y documentos; Opus quedaría como escalado.
