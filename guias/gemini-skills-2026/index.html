Gemini Skills

Cómo convertir prompts repetidos en procedimientos reutilizables.

PRECIO / DISPONIBILIDAD: rollout global en Gemini Chat para usuarios 18+, incluyendo cuentas gratuitas; Workspace llega por fases. No es una app separada.

Qué cambió

Google está migrando Gems a Skills. Una Skill guarda instrucciones, se invoca con /, puede usar archivos de referencia y combinarse con otras Skills.

Para quién sirve

Contenido, prospección, propuestas, análisis y operaciones repetibles.

Para quién no

No reemplaza un backend, webhooks ni un agente 24/7. Si la tarea no se repite, probablemente no necesita Skill.

Mapa de decisión

  • Prompt repetido: Skill.
  • Contexto estable: archivo + Skill.
  • Acciones externas: agente/integración.

3 casos

/prospecto -> problema probable + evidencia + mensaje
/gero_post -> hook + idea central + ejemplo + CTA
/propuesta -> alcance + riesgos + entregables + siguiente paso

Implementación

  1. Detectá un prompt que usás 3+ veces por semana.
  2. Separá instrucciones estables de variables.
  3. Definí output fijo.
  4. Probá 10 inputs reales.
  5. Corregí errores.
  6. Recién después compartila.

Gotchas

  • No mezclar 20 objetivos en una Skill.
  • Versionar cambios importantes.
  • Agregar reglas de no-inferencia cuando trabajás con datos.

Checklist

  • Nombre claro
  • Input esperado
  • Formato de salida
  • Ejemplos buenos/malos
  • Reglas de seguridad
  • Versión/fecha
