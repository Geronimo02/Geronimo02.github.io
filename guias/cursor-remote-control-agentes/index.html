Cursor Remote Control: controlar agentes locales desde el iPhone

PRECIO / DISPONIBILIDAD: Cursor lanzó Remote Control el 6 de octubre de 2026. La función está activada por defecto para todos salvo organizaciones Enterprise. El plan Hobby es gratis, sin tarjeta, y tiene solicitudes de Agent limitadas. Remote Control está disponible en la app de Cursor para iOS. El agente sigue ejecutándose en tu computadora: no es un Cloud Agent y tu equipo debe quedar encendido y online.

Qué cambió

Podés ver los agentes locales que están corriendo en tu computadora desde el iPhone, abrir uno, revisar qué está haciendo y mandarle un mensaje para corregir dirección o agregar contexto.

Por qué importa

Hasta ahora, un agente local largo te ataba bastante al escritorio. Esta función convierte el teléfono en una consola remota de supervisión. No hace que el trabajo ocurra en la nube: simplemente te permite controlar la sesión local a distancia.

Para quién sirve

  • Desarrolladores que dejan correr tareas largas de refactor o implementación.
  • Freelancers que alternan reuniones, calle y escritorio.
  • Personas que quieren supervisar un agente sin pagar por Cloud Agents.
  • Equipos chicos que usan Cursor local y necesitan intervenir rápido.

Para quién NO

  • Quien apaga la computadora o necesita que el trabajo continúe con el equipo dormido.
  • Usuarios Android por ahora.
  • Quien espera uso ilimitado de Agent en el plan gratuito: Hobby tiene límites.

Cómo funciona

  1. Instalá y abrí Cursor Desktop.
  2. Instalá Cursor en iOS e iniciá sesión con la misma cuenta.
  3. En el teléfono aparecerán las computadoras asociadas.
  4. Elegí una y aprobá el pairing desde Cursor Desktop.
  5. Abrí el agente local desde el iPhone.
  6. Leé el progreso o enviale un mensaje de steering.

Configuración que elegiría

Para una tarea larga activaría Keep this computer awake en Remote Control, dejaría el equipo enchufado y con la tapa abierta, y definiría antes de irme un criterio de éxito claro.

Workflow real

1. En el escritorio:
   “Implementá este ticket. Antes de cambiar arquitectura, avisame.”

2. Me voy del escritorio.

3. En iPhone:
   reviso progreso → veo si tomó una decisión equivocada → mando:
   “No agregues otra dependencia. Reutilizá la capa existente y seguí.”

4. Vuelvo con la tarea más avanzada y menos retrabajo.

Prompt de arranque

Objetivo: [ticket o tarea].
Antes de empezar, resumí el plan en 5 puntos.
No cambies arquitectura ni dependencias sin consultarme.
Trabajá por pasos verificables.
Después de cada bloque importante, dejá un resumen corto para que pueda supervisarlo desde Remote Control.
Si algo está ambiguo, frená antes de inventar.

Mapa de decisión

  • Necesito que corra aunque cierre la laptop: Remote Control no alcanza; necesitás ejecución cloud.
  • Mi laptop puede quedar encendida: Remote Control encaja muy bien.
  • Solo quiero revisar mensajes: úsalo como consola de supervisión.
  • Necesito ejecutar muchos agentes: revisá límites del plan y el costo antes de escalar.

Limitaciones

  • iOS en el lanzamiento.
  • La computadora debe estar encendida y conectada.
  • El plan Hobby incluye solicitudes de Agent limitadas.
  • Enterprise debe habilitar Remote Control desde la administración.
  • Control remoto no elimina la necesidad de revisar cambios importantes.

Qué haría yo

No lo usaría para “programar desde el celular”. Lo usaría para intervenir en el momento correcto. Lanzaría tareas bien especificadas desde el escritorio y usaría el teléfono para evitar que un error temprano se convierta en una hora de retrabajo.

Checklist

  • Cursor Desktop actualizado
  • Cursor iOS
  • Misma cuenta
  • Pairing aprobado
  • Equipo enchufado
  • Keep awake
  • Tarea bien acotada
  • Puntos de control definidos

Próximos pasos

Probalo con una sola tarea de 20–40 minutos. Si Remote Control te evita al menos una vuelta completa de corrección, ya encontró su lugar en el workflow.
