Meta Muse for Small Business

Un agente con contexto de ventas, operaciones y marketing.

PRECIO / DISPONIBILIDAD: anunciado el 29/09/2026 para EE.UU. y Canadá. Uso gratuito con límites y suscripciones para ampliar capacidad. No está confirmado para Argentina.

Qué cambió

Meta amplió Muse con skills y conectores para pequeños negocios. Puede trabajar con Instagram/Facebook Business y conectarse con Shopify, QuickBooks, Stripe, Slack, Notion, Canva, Klaviyo y otras herramientas.

Cómo funciona

Le das un objetivo y Muse usa el contexto conectado para analizar y preparar acciones. Meta dice que no publica, envía ni gasta sin aprobación del usuario.

Para quién sirve

Ecommerce, servicios, marketing, ventas y operaciones donde la información está repartida entre varias herramientas.

Para quién no

Negocios fuera de regiones habilitadas, equipos que no quieran conectar datos o procesos sensibles sin revisión humana.

Workflow

Shopify + Meta Ads + Instagram -> Muse analiza -> detecta oportunidad -> propone campaña -> humano revisa -> ejecuta lo aprobado

Qué probaría primero

  1. Conectar una sola fuente.
  2. Pedir análisis, no acciones.
  3. Validar que entienda productos, tono y clientes.
  4. Agregar una segunda herramienta.
  5. Recién después habilitar acciones aprobables.

Prompt

Analizá la última semana del negocio. Detectá 3 oportunidades accionables. Para cada una: evidencia, impacto probable, acción sugerida y herramienta involucrada. No publiques, no envíes y no gastes sin mi aprobación.

Comparativa

  • Muse: contexto nativo Meta + conectores.
  • Chat generalista: más flexible, menos contexto automático.
  • Automatización propia: más control, más setup.

Checklist

  • Revisar permisos
  • Empezar read-only
  • Separar análisis de ejecución
  • Definir acciones sensibles
  • Auditar cambios

Próximo paso

Yo lo usaría una semana como “analista conectado”. Si demuestra contexto correcto, recién ahí le daría acciones con aprobación.
